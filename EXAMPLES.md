# 🎯 Example Applications

This directory contains example applications demonstrating Universal Auth integration.

## 📂 Applications

### 1. Todo App (`client2/`)

A simple, beautiful todo application showcasing Universal Auth integration.

**Features:**
- ✅ Password & OTP authentication
- ✅ User registration with email verification
- ✅ Todo CRUD operations
- ✅ User-specific data storage
- ✅ Modern, responsive UI

**Quick Start:**
```bash
cd client2
npm install
npm run dev
```

**Access:** http://localhost:3001

**Documentation:** See `client2/README.md` for detailed setup instructions.

---

## 🔑 Setup Requirements

Before running any example app:

1. **Start Universal Auth backend:**
   ```bash
   npm run dev
   ```

2. **Register a domain** in the dashboard (http://localhost:3000)

3. **Copy your API key**

4. **Update the API key** in the example app's code
